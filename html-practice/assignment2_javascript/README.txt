ASSIGNMENT 2 - CORE JAVASCRIPT

Contains 10 separate JavaScript files, one for each question.

Run any file with Node.js:
    node q1_scope_conflict_resolver.js

You can also paste a file's code into the browser Developer Tools Console.
Change sample values in the files to test different cases.

Notes:
- Q1 demonstrates that the local isPermanent parameter controls the salary calculation,
  while the global bonus variable remains unchanged.
- Q8 applies category discounts per item, then checks the original cart total for the
  additional 5% overall discount, as specified.
