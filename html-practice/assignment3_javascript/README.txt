ASSIGNMENT 3 - CORE JAVASCRIPT

This folder contains 10 separate JavaScript files (one per question).

Run a file with Node.js:
    node q1_dynamic_data_parser.js

You can also run the files in a browser Developer Tools Console.
Q6 uses prompt() when running in a browser; otherwise it uses the default row count 5.

Debugging tasks:
- Open the folder in VS Code.
- Set breakpoints by clicking left of a line number.
- Press F5 / Run and Debug.
- Use Variables, Watch, and Call Stack panels to inspect execution.

Important:
- Q4, Q5, Q8, and Q10 include explanations and corrected examples for scope/hoisting.
- Q8's invalid strict-mode original is shown in comments because it would prevent the file from running.
