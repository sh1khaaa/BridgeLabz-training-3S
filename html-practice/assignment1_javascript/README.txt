ASSIGNMENT 1 - CORE JAVASCRIPT

This folder contains one separate JavaScript file for each of the 10 questions.

How to run:
1. Open a file in VS Code.
2. Run it with Node.js using: node filename.js
   OR copy the code into a browser's Developer Tools Console.
3. Change the sample values near the top of the file to test other cases.

Notes:
- All programs use core JavaScript only.
- Comments explain the main logic.
- Q10's wording has overlapping conditions: "citizen and age >= 18" includes the 18-20 vote-only range.
  To make both outcomes reachable, this solution interprets ages 18-20 as vote-only and age 21+ as all services.
