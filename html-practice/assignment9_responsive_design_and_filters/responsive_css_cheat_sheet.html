Responsive CSS Cheat Sheet

Quick notes for everyday frontend practice.

Filters

Change the appearance of images using CSS filter functions.

filter: grayscale(100%);

Media Queries

Apply different styles when the viewport meets a condition.

@media (max-width: 700px) { ... }

Responsive Design

Make layouts adapt to phones, tablets, and desktops.

width: min(100%, 900px);

Typography

Use relative sizes to keep text readable on every screen.

font-size: clamp(1rem, 2vw, 1.5rem);
