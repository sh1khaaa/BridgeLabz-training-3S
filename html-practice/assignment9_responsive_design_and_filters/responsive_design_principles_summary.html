Three Principles of Responsive Design

Core ideas for flexible and accessible layouts.

Fluid Layouts

Use flexible widths and relative units so content can expand or shrink with the viewport.

.container { width: 90%; }

Flexible Media

Images and videos should fit inside their containers without overflowing.

img { max-width: 100%; height: auto; }

Breakpoints

Media queries adjust layout when the available screen width changes.

@media (max-width: 600px) { ... }
Responsive design makes content work across devices.
